GastosCasaJD v3

Nuevas funciones:
1. Muchos grupos de gastos: Casa, Carro, Salud, Educación, Transporte, Alimentación, Mascotas, Ropa, Entretenimiento, Deudas, Seguros, Impuestos, Suscripciones, Viajes, Trabajo, Ahorro, Regalos y Otros.
2. Categorías cambian según el grupo.
3. Menú "Pendientes": gastos que todavía no se han pagado. Se pueden eliminar o convertir en gasto cuando se paguen.
4. Menú "Lista de compras": productos faltantes, cantidad, categoría y nota. Se pueden marcar como comprados o eliminar.
5. Todo se sincroniza con Supabase.

IMPORTANTE:
- Primero ejecuta supabase_v3.sql en Supabase SQL Editor.
- Después reemplaza index.html, script.js y style.css en GitHub.
- No necesitas borrar el repositorio.
